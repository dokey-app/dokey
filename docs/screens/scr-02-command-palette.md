# SCR-02 · Командная палитра

**Реестр:** [screen-map.md](../screen-map.md) §2 · **Тип:** оверлей поверх маршрута ·
**Роль:** ROLE-01 · **Сущности:** ENT-09, ENT-02, ENT-01
**Сценарии:** FL-08 целиком · FL-09 шаги 2 и 4 · FL-01 A3 · FL-03 A1
**Истории:** US-014, US-063
**Решено:** входов три — Ctrl/Cmd + K, кнопка в шапке, `/` (D-62); «нажатие» — действие, а не клавиша, шесть инструментов за два действия (D-73, D-81); поиск по именам, синонимам и с нормализацией раскладки (D-82); «недавних» пять, LRU, только в памяти (D-83)

---

## 1. Зоны макета

Единственный слой продукта, который физически перекрывает работу, — и поэтому единственный
носитель тени `--shadow-lg` и единственное скругление `--radius-md` 6px (design-plan §5.4).
Если тень появится где-то ещё, она перестанет означать «перекрывает работу».

| Зона | Содержимое | Токен |
|---|---|---|
| A · строка поиска | Поле в фокусе с момента открытия, без плейсхолдера-инструкции | `--type-code` 15/23 |
| B · список | Позиции каталога: имя инструмента и описание до 55 знаков в одной строке | имя `--type-ui`, описание `--type-caption` `--text-muted` |
| C · заголовок группы | `Недавние` — только когда строка поиска пуста | `--type-caption`, регистр предложения |
| D · пустое состояние | Одна из двух строк §4, на месте списка | `--type-ui` |
| E · подсказка клавиш | `Esc` для закрытия, стрелки для перемещения, в `kbd` | `--type-caption` |

Ширина — не более `--measure-bench` 88ch и не более 90 % вьюпорта. Подложка под оверлеем —
`--ink` с прозрачностью, без блюра.

**Совпадение подсвечивается акцентной подложкой `--surface-accent-soft` с чернильной чертой 2 px снизу** — тем же приёмом,
которым размечает данные определитель. Одно акцентная подложканое пятно на строку: если совпало два фрагмента,
подсвечивается первый, иначе разметка превращается в раскраску (design-plan §5.1, правило 2).

## 2. Приоритет элементов

1. **Строка поиска.** Палитра открывается ради набора, а не ради чтения списка.
2. **Первая позиция списка.** Она предвыбрана: `Enter` сразу после открытия должен что-то делать,
   иначе правило двух нажатий не выполняется.
3. **Имя инструмента.** Отличает JSON-форматтер от JSON-валидатора — иконка не отличает, поэтому
   иконок в списке нет (design-plan §4).
4. **Описание позиции.** 55 знаков, вторичный цвет, служит различению, а не рекламе.
5. **«Недавние».** Верх списка при пустом запросе — самый дешёвый путь для вернувшегося.
6. **Подсказка клавиш.** Нижняя строка, `--type-caption`; на мобильном отсутствует.

Иконок в палитре нет ни у одной позиции. Это не экономия, а решение: минус один бандл иконок
из бюджета NFR-03 и минус ложное различение.

## 3. Поведение на мобильном

**Вызов на мобильном закрыт D-62: постоянная кнопка палитры в шапке** — она же единственный
вход там, где `Ctrl + K` не существует, и она же обход перехваченного сочетания на десктопе.
Сценарий FL-08 проходится. Остальное:

- Оверлей занимает почти весь экран: поля 16 px, список во всю ширину, тень сохраняется.
- Строка поиска остаётся в фокусе; появление системной клавиатуры не должно скрывать первую
  позицию списка — она обязана оставаться видимой над клавиатурой.
- Высота строки списка увеличивается до 44 px (цель нажатия WCAG 2.5.8 с запасом), шаг между
  строками 8 px. Кегли не меняются: `--type-ui` и `--type-caption` те же, что на десктопе.
- Подсказка клавиш `Esc` скрывается; закрытие — нажатием вне оверлея и системной кнопкой «назад».
- Анимация открытия 120 мс сохраняется и обнуляется при `prefers-reduced-motion`.

## 4. Тексты

| Место | Строка |
|---|---|
| Заголовок группы недавних | `Недавние` |
| «Недавние» пусты | `Пока пусто. Здесь появятся инструменты, открытые в этой вкладке` |
| Поиск без совпадений | `Ничего не нашлось. В каталоге шесть инструментов — сотрите запрос, чтобы увидеть все` |
| Описание позиции, образец | `Разбор header и payload, проверка подписи` |

Запрос пользователя в пустом состоянии **не цитируется** (CG-18): `Ничего не нашлось`, а не
`По запросу «‹…›» ничего не нашлось`.

**Запрещено здесь.** `История`, `Журнал`, `Недавние операции` — категорически, слово «недавние»
относится только к инструментам (глоссарий §6) · `НЕДАВНИЕ` капителью (CG-02) · `Ошибка`, `Упс`,
`Не поддерживается` в пустом состоянии (CG-04) · `Поиск` как единственная подпись механизма —
теряется, что это палитра · русские переводы имён инструментов (CG-12).

**Расхождение, которое нужно снять до вёрстки.** Строка пустого состояния говорит «шесть
инструментов», критерий US-014 требует достижимости восьми позиций каталога. Две из восьми —
механизмы ядра без маршрута, открыть их нельзя. Текст и критерий обязаны сойтись — **D-81**.
