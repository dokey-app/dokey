# UI kit — ToolBox PWA (мобильный)

Мобильная оболочка того же портала: 390×700, тач-цели не меньше 44px, нижняя навигация из четырёх разделов.

**Экраны**
- `MobileApp.jsx → MobileList` — поиск, горизонтальная лента категорий, список инструментов строками (иконка 36px в мягкой акцентной плитке, название, категория, шеврон), карточка установки PWA, нижний таб-бар.
- `MobileApp.jsx → MobileTool` — инструмент в один столбец: поле ввода, строка статуса с бейджами и копированием, сегментированные вкладки, кодовая панель, основная кнопка на всю ширину.
- `PhoneFrame.jsx` — рамка устройства со статус-баром; левый экран светлый и кликабельный, правый показывает тёмную тему.

Отличия от десктопа: сайдбар заменён таб-баром, двухколоночный рабочий стол становится вертикальным стеком, primary-кнопка растягивается на ширину экрана.
