# UI kit — ToolBox portal (десктоп)

Кликабельная рекреация основного продукта: каталог ИТ-сервисов и рабочий стол отдельного инструмента.

**Экраны**
- `CatalogScreen.jsx` — витрина инструментов: H1 + подзаголовок, фильтр-теги категорий, сетка `ToolCard` (auto-fill, minmax 238px, gap 16), пустое состояние.
- `JwtDecoderScreen.jsx` — двухколоночный рабочий стол: ввод токена с посегментной подсветкой слева, результат (Payload / Header / Claims) и блок проверки подписи справа, тост об успешной проверке.
- `Base64Screen.jsx` — второй инструмент того же каркаса: ввод ↔ результат, сегментированный переключатель режима, настройки под полем ввода.
- `AppShell.jsx` — липкая шапка (вордмарк, поиск с ⌘K, статус офлайна, переключатель темы, аватар) и сайдбар 244px с недавними инструментами и PWA-промо.

**Взаимодействия**: клик по плитке открывает инструмент, сайдбар переключает экраны, переключатель темы меняет `data-theme` на корне, вкладки/переключатели/тост работают.

Данные инструментов вынесены в `tools.data.jsx`. Все примитивы берутся из скомпилированного бандла дизайн-системы — внутри кита ничего не переопределяется.
