# Продукт

## Что это

DoKey — утилиты разработчика в браузере: JSON, JWT, Base64, URL, Unix timestamp, UUID/ULID.
Пользователь — инженер (backend, frontend, QA, DevOps), которому посреди другой работы нужно
за полминуты разобрать токен, конфиг или ответ API. Без аккаунта, рекламы и сомнения
«можно ли сюда вставить боевой секрет».

**Обещание:** ввод и результат не покидают вкладку. Это не заявление, а проверяемое свойство:
сервера, аккаунтов, хранения и аналитики нет, CSP разрешает запросы только своему origin, а
счётчик внешних запросов на странице показывает 0. Формулировки — проверяемые
(`Внешних запросов: 0 · Как это проверить`), не «100 % приватность» и не «ваши данные
в безопасности».

**Никогда:** сервер, БД, аккаунты, шеринг ссылкой, сетевые AI-вызовы, сторонние скрипты и
шрифты, запись ввода куда-либо (storage, URL, история). Подделка браузерного API тоже
запрещена: `Math.random` вместо `crypto.getRandomValues`, «Скопировано» без копирования.

## v1 — релиз 2026-12-21

Интерфейс только на русском. Домен `dokey.ru`.

| Маршрут           | Имя (не переводится)     | Что делает                                                                |
| ----------------- | ------------------------ | ------------------------------------------------------------------------- |
| `/`               | —                        | Поле ввода с автоопределением и чипсами-кандидатами                       |
| `/json`           | JSON Workbench           | Формат, минификация, проверка с позицией ошибки, дерево, копирование пути |
| `/jwt`            | JWT Inspector            | header/payload/signature, `exp`/`iat`/`nbf`, проверка HS256               |
| `/base64`         | Base64 Encoder/Decoder   | Текст и файл, UTF-8, URL-safe алфавит                                     |
| `/url`            | URL Encoder/Decoder      | Encode/decode, разбор URL на компоненты, таблица query                    |
| `/unix-timestamp` | Unix Timestamp Converter | Секунды/мс ↔ ISO 8601, UTC и локальное время                              |
| `/uuid`           | UUID/ULID Generator      | Генерация v4/v7/ULID пакетом, разбор и проверка                           |
| `/how-to-verify`  | —                        | Как проверить обещание самому; обязательства оператора; контакт           |

Slug называет формат, а не действие, и **не меняется после релиза**. Лендинг и инструмент —
одна страница: H1, вводный абзац, пример и FAQ видны без JS.

### Общее для всех инструментов

- Результат — в отдельной области; ввод им не заменяется. До ввода там разобранный `Пример`.
- Ошибка — за ≤ 300 мс, с позицией (строка, позиция); `Перейти к ошибке` ставит курсор на
  место ошибки в поле ввода (подсветки внутри `textarea` нет). Ввод не очищается.
- Порог размера: выше мягкого — предупреждение и кнопка `Обработать`; выше жёсткого — отказ
  без продолжения. Число порога в тексте называется всегда. Пороги — 2 МБ и 10 МБ (UTF-8);
  до мягкого порога обработка идёт по мере ввода.

### JSON

Форматирование применяется само (отступ 2 пробела); чипсы `Форматировать`/`Минифицировать`,
флажок `Сортировать ключи` (рекурсивно, массивы не трогает). Числа и строки выводятся в
исходной записи: `12345678901234567890`, `1.0`, `1e7` не переписываются; повторяющиеся ключи
сохраняются. Ошибки вида `Ожидалась запятая. Строка 12, позиция 34`, `Лишняя запятая перед }`,
`Строки в JSON берутся в двойные кавычки, а не в одинарные`. Пустой объект/массив — валидный
документ. Вложенность — до 1000 уровней, глубже — отказ с объяснением.

Дерево — `Развернуть`/`Свернуть` (`Развернуть` скрыт, если узлов больше 5000), дети строятся
при раскрытии порциями по 1000 (`Показать ещё`). Фокус или клик по узлу выбирает его; строка
«Путь» над деревом показывает JSONPath (`$.user["first name"]`) и `Скопировать путь`.

### JWT

- Не три сегмента → `Ожидались три сегмента, разделённые точкой. Найдено два`.
- `exp`/`iat`/`nbf`: исходное число, UTC и локальное время со смещением; метка
  `Истёк · 1 января 2026, 03:00 UTC · 4 часа назад`. Нет `exp` — не ошибка.
- Подпись: `Подпись не проверялась` / `Подпись верна` / `Подпись не совпала. Проверьте ключ
подписи и алгоритм`. Только HS256 через WebCrypto; алгоритм берётся из `alg`, не
  подменяется. Вердикт «токен валиден» запрещён.
- RS256/ES256: `Подпись RS256 локально не проверяется — нужен открытый ключ.`
  `alg: none`: `Токен не подписан (alg: none). Подтвердить его подлинность нечем.`
- Поле ключа свёрнуто, маскируется `Показать`/`Скрыть` (не `type="password"`),
  `autocomplete="off"`, `spellcheck="false"`. Без `crypto.subtle` (http) разбор работает,
  проверка — нет.
- Уход со страницы обнуляет токен, ключ и производные значения.

### Base64

Чипсы `Текст`/`Файл`. Ошибка: `Некорректная base64-строка: длина не кратна четырём.
Возможно, при копировании потерялся хвост`. Файл: `Выбрать файл`, «имя · размер», чтение
частями, прогресс не раньше 400 мс, `Отменить` возвращает исходное состояние.

### URL

Полный URL раскладывается на схему, хост, порт, путь, query, фрагмент (пустые не
показываются). Query — таблица «ключ — значение», повторяющиеся ключи не схлопываются.
Оборванная `%`-последовательность — ошибка с позицией. `URL-кодировать` — только по нажатию.

### Unix timestamp

10 цифр — секунды, 13 — миллисекунды; чипсы `Секунды`/`Миллисекунды` переопределяют.
ISO 8601 на вход. Ни одно время не показывается без зоны. Текущее время до ввода не выводится.

### UUID/ULID

Чипсы `v4`/`v7`/`ULID`, количество, `Сгенерировать`; одно значение уже на первом кадре.
`Скопировать` у строки и у пакета. Только `crypto.getRandomValues`; без него значений нет.
Разбор: корректность, версия, вариант; у ULID — время.

### Автоопределение (`/`)

Лестница от специфичного к общему: JWT → JSON → UUID/ULID → URL → percent → timestamp →
base64 → текст. Побеждает первый кандидат с **осмысленным** результатом, он применяется
сразу; остальные — чипсами в порядке лестницы. Ручной выбор сильнее автоопределения.
«Распознано как…» и «тип не распознан» не пишем — состояние передаёт активный чипс.
Распознаватели линейны (без вложенных квантификаторов и обратных ссылок).

## Тексты

- Голос точный и будничный: вместо прилагательного — число или ссылка. На «вы», без «я».
- Ошибка — «что случилось + как исправить», ≤ 2 предложений и 120 знаков; ввод не цитирует.
- Не извиняться, не пугать, не обещать сроки. Стоп-слова: мгновенно, просто, удобно,
  безопасно, надёжно, гарантируем, 100 %.
- Регистр как в предложении, без «!» и эмодзи, без точки в подписях; кнопка ≤ 20 знаков.
- Данные (то, что копируют) не форматируются; метаданные — по-русски: `1,4 МБ`, `840 мс`.
- `Скопировать` → `Скопировано` на 1,2 с, без тостов. `Очистить` без подтверждения.
  Отказ буфера: `Браузер не дал доступ к буферу обмена. Выделите результат и скопируйте: Ctrl + C`.

Словарь (в скобках — нельзя): чипс (чип, таб) · порог (лимит) · ключ подписи (секрет, пароль)
· декодировать (расшифровать) · `Истёк` (просрочен) · инструмент (сервис, утилита) ·
«Как это проверить» (Приватность).

## Доступность

WCAG 2.2 AA. Всё проходится клавиатурой; поле ввода в фокусе с первого кадра; `:focus-visible`
виден всегда. `role="status"` — результат и «Скопировано»; `role="alert"` — ошибки и отказ по
порогу. Тема следует системе (`prefers-color-scheme`), без переключателя. Цвет никогда не
единственный носитель смысла. Цель нажатия ≥ 24 px. Без горизонтальной прокрутки на мобильных.
