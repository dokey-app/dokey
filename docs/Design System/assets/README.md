Логотипов, иллюстраций и изображений в источниках не было — вордмарк набирается типографикой (см. «Iconography» в readme.md), иконки — инлайн-спрайт из восьми глифов, собираемый вместе со сборкой (D-54 п. 3); зависимость Lucide не берётся ни в каком виде, формы глифов скопированы из Lucide (ISC) с атрибуцией в репозитории.

Пришлите SVG логотипа, favicon и любые фирменные изображения — они лягут сюда, и вордмарк в UI-китах будет заменён на настоящую марку.
