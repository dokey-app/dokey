# Безопасность

## Что защищается

DoKey — статический сайт: сервера приложения, базы данных и аккаунтов нет по построению.
Обещание продукта одно и проверяемое: **ввод не покидает вкладку.** Инвариант держится ответом
`Content-Security-Policy` с `script-src 'self'` и `connect-src 'self'` и проверяется тестами
на каждой сборке.

## Куда сообщать

Уязвимость — письмом на `security@dokey.ru` или приватным advisory в GitHub
(«Security» → «Report a vulnerability»). **Публичный issue для уязвимостей не подходит.**

Ответ — в течение 5 рабочих дней. Исправление и раскрытие согласуются с тем, кто сообщил.

## Что особенно интересно

- Любой способ отправить ввод пользователя за пределы вкладки.
- Обход CSP, XSS через враждебный JSON или JWT.
- Запись ввода в `localStorage`, `sessionStorage`, URL, историю.

## Что не считается уязвимостью

Остаточные риски названы прямо и не скрываются: расширения браузера, общий экран,
корпоративный прокси с подменой TLS, служебный ключ в устройстве пользователя. От них
статический сайт защитить не может — и не заявляет, что может.
