# Как участвовать

## Прежде чем писать код

**Сначала issue, потом PR** (D-21). Предложение инструмента идёт по шаблону
«Предложить инструмент» — он повторяет пункты контракта и работает как самофильтр.
Отказ всегда называет пункт контракта, которому предложение не соответствует, а не вкус
мейнтейнера. Право не принимать то, что мейнтейнер не готов сопровождать вечно, — часть
контракта, а не исключение из него.

## Контракт инструмента (D-21)

Позиция принимается, если выполнены **все** пункты:

1. Четыре критерия D-04: вычислимо в браузере без сети; на входе текст или небольшой файл;
   решение занимает секунды; аудитория — разработчик.
2. Единая форма: одно поле ввода, область результата, чипсы вариантов. Собственных
   layout-решений нет.
3. Бюджет ленивого чанка соблюдён; тяжёлая зависимость требует отдельного обоснования.
4. Фикстуры добавлены в корпус определителя — иначе новый тип данных ломает лестницу.
5. Обе локали и запись в реестре `src/registry`.

## Красные линии

Ни одно из этого не принимается, и это не «пока», а устройство продукта:

- **Сторонний origin.** Ни CDN, ни шрифтов Google, ни SDK телеметрии — `script-src` и
  `connect-src` равны `'self'` (ИНВ-01, гейт G-04).
- **Запись ввода куда бы то ни было** — `localStorage`, `sessionStorage`, URL, query,
  фрагмент, история (ИНВ-02, гейт G-03).
- **Фреймворк в бандле** — React, Preact, Svelte, Vue, Tailwind, иконочные библиотеки.
  Бюджет initial JS — 40 KB gzip (гейт G-02).
- **Сервер, база, очередь, аутентификация, шеринг.**
- **Подделка возможности браузерного API:** `Math.random` вместо `getRandomValues`,
  «Скопировано» без копирования, своя криптография ради `http`.

## Порядок работы

```bash
pnpm install
pnpm dev                 # каркас
pnpm lint && pnpm format:check && pnpm typecheck
pnpm test:unit && pnpm test:int && pnpm test:e2e
pnpm gates               # все четырнадцать
```

Требуются Node.js 24 LTS и pnpm 12.3.4. Версии в манифесте пиннятся **точно**: `^` и `~`
запрещены.

## Ветка, коммит, PR

Ветка — `t-042-json-tree` по номеру задачи из `docs/tasks.md`. Один коммит на задачу:
`T-042: дерево JSON (US-020)`. Отметка `- [x]` в `docs/tasks.md` идёт тем же коммитом.

**PR обязателен.** Прямой пуш в `main` закрыт: гейты живут на PR, и способа выпустить сборку
мимо них нет — сознательно. История линейная.

**Найденное попутно не чинится в том же PR.** Правка не по теме задачи в диффе — дефект PR,
а не бонус: строка `- [ ]` в `docs/tasks.md` либо вопрос `Q-NN` в `docs/open-questions.md`.

## Имена

Сущности, поля и роли — английские из `docs/glossary.md`, единственное число: `Tool`, `Route`,
`TypeDetector`, `AppShell`, `Maintainer`. Интерфейс и документы — русская колонка глоссария.
Файлы — lowercase-kebab, типы и `.astro` — PascalCase. События аналитики — `объект_действие`.
