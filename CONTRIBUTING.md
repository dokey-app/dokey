# Как участвовать

## Сначала issue

Предложение инструмента — по шаблону «Предложить инструмент». Инструмент принимается, если:

1. Вычисляется в браузере без сети; на входе текст или небольшой файл; результат за секунды;
   аудитория — разработчик.
2. Использует общую форму: поле ввода, область результата, чипсы. Своих layout-решений нет.
3. Не выводит страницу за бюджет initial JS 40 KB gzip; тяжёлая зависимость — с обоснованием.
4. Добавлен в `src/registry/tools.ts`, с юнит-тестами логики и e2e-сценарием.

Мейнтейнер вправе не принять то, что не готов сопровождать.

## Красные линии

Не принимается никогда — это устройство продукта, а не «пока»:

- Сторонний origin: CDN, шрифты Google, SDK телеметрии. `script-src`/`connect-src` = `'self'`.
- Запись ввода куда бы то ни было: storage, cookie, URL, история.
- Фреймворк в бандле: React, Preact, Svelte, Vue, Tailwind, иконочные библиотеки.
- Сервер, база, аутентификация, шеринг.
- Подделка браузерного API: `Math.random` вместо `getRandomValues`, «Скопировано» без
  копирования.

## Работа

Node.js 24, pnpm 12.3.4. Версии зависимостей пиннятся точно, без `^` и `~`.

```bash
pnpm install
pnpm dev
pnpm check    # перед PR: то же, что CI
```

Ветка на изменение, PR в `main`, мерж после зелёного CI. Сообщения коммитов — обычные,
описательные. Тексты интерфейса — по правилам из [docs/product.md](docs/product.md).
