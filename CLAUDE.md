**Ввод физически не покидает вкладку:** сервера, аккаунтов, истории и хранения нет по построению.

## Код, структура, имена

Исходов у гейта три: `pass`, `pending('Э-N')` пока предмета нет, `fail`. **«Пусто» за «проверено» не выдаётся:** проверка, не нашедшая предмета, возвращает проблему или `pending`, а не пустой список.
Стили — нативный CSS с токенами `Design System/`. `src/registry` — единственный источник маршрутов, **список маршрутов в тесте не пишется руками**; остальные каталоги — по компоненту КМП-NN, состав в `src/README.md`, каталога вне его таблицы не заводить. Вне `src`: `infra/ scripts/ fixtures/`; `tests/`: `unit` · `integration` · `e2e` · `invariants` · `system` · `gates/negative`.
Сущности, поля, роли — **английские из `docs/glossary.md`**, единственное число (`Tool`, `Route`, `AppShell`); интерфейс и документы — русская колонка, синоним из glossary §6 — дефект, а не стиль. Файлы lowercase-kebab, типы и `.astro` — PascalCase, события аналитики — `объект_действие`.

- **Язык с контекстом разбирает лексер своего инструментария** (`es-module-lexer`, лексер Vite, D-158), а не регулярка: регулярка — только для фиксированной грамматики, и тогда всё, что под неё не подошло, — провал, а не молчаливый пропуск; файл читается так, как его декодирует потребитель (BOM, CRLF). **Второй класс ошибок в самописном разборе — вопрос о настоящем парсере, а не третья заплатка.**
- **Закрывается класс, а не найденная форма:** исправление идёт во все однотипные единицы в один заход — во второй разборщик того же гейта, во все job'ы, во все файлы того же рода. Перечень годного — белый список, а не список непригодных форм; требование к чужому ключу читается в документации принимающей системы, и её молчание — не разрешение; правило, заведённое уроком, сверяется с собственным диффом.
- **Файлы правятся Edit/Write, а не `sed` по номерам строк:** формат, линт, расширение в относительном импорте и `gate:headers-parity` держит хук `PostToolUse`, и правка мимо него доживает до коммита молча.

## Запрещено — инварианты architecture §10, причины и гейты в agent-rules §6

- **IMPORTANT: ввод и результат не покидают вкладку.** `script-src`/`connect-src` = `'self'`; ни CDN, ни Google Fonts, ни Sentry, ни SDK телеметрии — сторонних origin ровно 0 (ИНВ-01, `gate:egress`)
- **Ввод никуда не пишется:** `localStorage`, `sessionStorage`, URL, query, фрагмент, история — персистентность равна нулю (ИНВ-02, `gate:persist`)
- **Маршрут не заводится мимо `src/registry`**, и сам `registry` не импортирует `shell` и `tools` (ИНВ-06); запись в `registry/tools.ts` — последняя задача среза, `Tool.id` после релиза неизменен (ИНВ-07)
- **Поля аналитики не добавляются** — наружу идёт только закрытый список ENT-29 (ИНВ-05, `gate:fields`) · **фреймворка в бандле нет** — initial JS ≤ 40 KB gzip (`gate:size`). До Э-1 гейты инвариантов отвечают `pending` — держит их только это правило
- **Ни сервера, ни БД, ни очереди, ни аутентификации, ни шеринга** — красные линии D-05, это не «пока» · **возможность браузерного API не подделывается:** `Math.random` вместо `getRandomValues`, «Скопировано» без копирования, своя криптография ради `http`
