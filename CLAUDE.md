# DoKey

Утилиты разработчика в браузере: JSON, JWT, Base64, URL, Unix timestamp, UUID/ULID.
**Ввод и результат не покидают вкладку** — сервера, аккаунтов, хранения и аналитики нет.
Статический Astro + ванильный TypeScript, хостинг Cloudflare Workers. Релиз v1 — 2026-12-21.

- Что строим и тексты интерфейса — [docs/product.md](docs/product.md)
- Как устроено — [docs/architecture.md](docs/architecture.md), решения — [docs/decisions.md](docs/decisions.md)
- Что дальше — [ROADMAP.md](ROADMAP.md): берём первый незакрытый пункт текущего среза
- Домен, деплой, токены — [docs/ops.md](docs/ops.md)
- `docs/archive/` — старые документы, только справка; сверять с ними не нужно

## Команды

- `pnpm dev` — локально на :4321
- `pnpm check` — всё, что делает CI: lint, format:check, typecheck, test:unit, test:e2e
- `pnpm test:unit` — Vitest в node (логика инструментов); `pnpm test:e2e` — сборка + Playwright
- Prettier и oxlint на изменённый файл запускает хук PostToolUse

## Инварианты (тесты в `tests/e2e/` ловят первые три)

- **Ни одного запроса на сторонний origin.** Без CDN, Google Fonts, Sentry, телеметрии;
  CSP `script-src`/`connect-src 'self'` в `public/_headers`.
- **Ввод никуда не пишется:** localStorage, sessionStorage, cookie, IndexedDB, URL, history.
- **Initial JS ≤ 40 KB gzip на страницу.** Фреймворков (React, Preact, Vue, Svelte) нет.
- **Ввод в DOM — только `textContent`.** `innerHTML` и родственники запрещены линтом.
- **Маршрут инструмента — только из `src/registry/tools.ts`.** `Tool.id` после релиза не меняется.
- **Браузерные API не подделываются:** `crypto.getRandomValues`, а не `Math.random`;
  «Скопировано» — только после реального копирования.
- Без сервера, БД, аккаунтов, шеринга ссылкой — это не «пока», а суть продукта.

## Как работаем

- Срез из ROADMAP = ветка (`json-tool`) + PR; мерж после зелёного CI, `main` деплоится сам.
- Коммиты — обычные описательные сообщения на английском.
- Мелочь, найденная попутно, чинится в том же PR. Крупное — строкой в ROADMAP.
- Решение, которое дорого отменить (новая зависимость, смена хостинга, публичный URL), —
  строкой в `docs/decisions.md` в том же PR.
- Тексты интерфейса — по правилам и словарю из `docs/product.md`.
- Логика инструмента — чистые функции в `src/tools/<id>/logic.ts` с юнит-тестами;
  у каждого инструмента есть e2e-сценарий «вставил → получил результат → скопировал».
- e2e импортируют `test`/`expect` из `tests/e2e/fixtures.ts` — так тест идёт под продовой CSP.
- Без инлайн-скриптов и `style`-атрибутов: CSP их блокирует. Стили — в `<style>` компонента;
  до узлов, созданных JS, scoped-стили не доходят — для них `.parent :global(.child)`.
- Чипсы, которые может выставить автоопределение, слушают `click`, а не `change`: клик по уже
  отмеченной радиокнопке `change` не даёт, и ручной выбор не закрепится.
- Ввод обрабатывается с задержкой — действие над результатом (копировать, проверить) сначала
  выполняет отложенный пересчёт (`flush()` в `ui.ts`), иначе работает с прежним вводом.
- Код и идентификаторы — английские; интерфейс и документы — русские.
