**Ввод физически не покидает вкладку:** сервера, аккаунтов, истории и хранения нет по построению.

## Код, структура, имена

Скрипты и гейты исполняет `node --experimental-strip-types`, не tsx: **относительный импорт всегда
с расширением** — `from './gate.ts'`. Гейт — `scripts/gates/<имя>.ts` по образцу соседа: `export
const gate: Gate` и хвост `runGate(gate)`, исходов три — `pass`, `pending('Э-N')` пока предмета нет,
`fail`; «пусто» за «проверено» не выдаётся. Стили — нативный CSS с токенами `Design System/`.
`src/registry` — единственный источник маршрутов; остальные каталоги — по компоненту КМП-NN, состав
и назначение в `src/README.md`, каталога вне его таблицы не заводить. Вне `src`: `infra/ scripts/ fixtures/`;
тесты — `tests/unit` (RUN-01, node) · `integration` (RUN-02, браузер) · `e2e` (RUN-03) · `invariants`
(прогон по всем маршрутам) · `system` (образ и поставка) · `gates/negative` (сборки, ломающие гейт
намеренно). **Список маршрутов в тесте не пишется руками — берётся из реестра.** Сущности, поля, роли
— **английские из `docs/glossary.md`**, единственное число (`Tool`, `Route`, `TypeDetector`, `AppShell`,
`Maintainer`); интерфейс и документы — русская колонка, синоним из glossary §6 — дефект, а не стиль.
Файлы lowercase-kebab, типы и `.astro` — PascalCase, события аналитики — `объект_действие`.

## Запрещено — инварианты architecture §10, причины и гейты в agent-rules §6

- **IMPORTANT: ввод и результат не покидают вкладку.** `script-src`/`connect-src` = `'self'`; ни CDN, ни Google Fonts, ни Sentry, ни SDK телеметрии — сторонних origin ровно 0 (ИНВ-01, `gate:egress`)
- **Ввод никуда не пишется:** `localStorage`, `sessionStorage`, URL, query, фрагмент, история — персистентность равна нулю (ИНВ-02, `gate:persist`)
- **Маршрут не заводится мимо `src/registry`**, и сам `registry` не импортирует `shell` и `tools` (ИНВ-06); запись в `registry/tools.ts` — последняя задача среза, `Tool.id` после релиза неизменен (ИНВ-07)
- **Поля аналитики не добавляются** — наружу идёт только закрытый список ENT-29 (ИНВ-05, `gate:fields`) · **фреймворка в бандле нет** — initial JS ≤ 40 KB gzip (`gate:size`)
- **Ни сервера, ни БД, ни очереди, ни аутентификации, ни шеринга** — красные линии D-05, это не «пока» · **возможность браузерного API не подделывается:** `Math.random` вместо `getRandomValues`, «Скопировано» без копирования, своя криптография ради `http`
- **Архитектурное решение внутри задачи не принимается** — оно идёт в `open-questions.md` как Q-NN

## Работа

Одна сессия = одна задача из `docs/tasks.md`, взятая **верхней** `- [ ]`: `⚠ Q-NN` — не брать,
`блок: T-NNN` — сначала та. План, который не влезает на экран, трогает > 5–7 файлов или требует
решения, которого нет ни в decisions, ни в tasks, — режется. Ветка `t-042-json-tree`, **коммит
`T-042: дерево JSON (US-020)`** — не conventional commit; отметка `- [x]` в нём же. PR обязателен,
прямой пуш в `main` закрыт (remote заводит T-002 — до неё коммит остаётся локальным). **Найденное
попутно не чинить:** строка `- [ ]` в tasks.md либо `Q-NN` в open-questions.md; правка не по теме в
диффе — дефект PR, а не бонус. **Перед коммитом** — чек-лист `.github/pull_request_template.md`
целиком: линт, формат, типы, затронутые уровни тестов, команда из графы «готово», гейты по предмету.
Тексты — дословно из `content-guide.md` и glossary §4, пороги — `data-model.md`. Трогали лестницу —
фикстуры в том же PR.
